02 / Featured repositories

Prominence needs a reason.

GitHub projects are ranked with public community, documentation, recency and relevance signals—not random placement.

How ranking works

The feature score combines logarithmically scaled stars and forks, repository description/topics/homepage/license signals, update recency, and keyword relevance to AI, research, software and evaluation. Archived work is deprioritized.
